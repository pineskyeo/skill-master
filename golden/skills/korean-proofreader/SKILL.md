# Korean Proofreader
## Inputs
- text: the Korean sentence or document to proofread
## Outputs
- corrected_text (in Korean), changes (the list of changed parts)
## Example
Input: a Korean phrase with one spacing error and one spelling error. Output: the corrected phrase, with changes listing one spacing fix and one spelling fix.
