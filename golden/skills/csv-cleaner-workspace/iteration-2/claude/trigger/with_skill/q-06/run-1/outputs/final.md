작업 디렉터리에 CSV 파일이 없어요. 파일 경로를 알려주시면 바로 처리할게요.

참고로, 공백만 제거하는 방식으로 진행할 예정입니다.
- 모든 셀 값의 앞뒤 공백만 제거 (`' 서울 '` → `'서울'`), 값 중간의 공백은 그대로 둡니다.
- 중복 행 제거는 하지 않습니다. (`csv-cleaner` 스킬은 중복 제거까지 같이 하기 때문에, 요청하신 "공백만"에는 맞지 않아 사용하지 않고 직접 처리하겠습니다.)
- 원본은 건드리지 않고 새 파일로 저장합니다. (예: `원본이름_trimmed.csv`)

ERP 추출 CSV는 인코딩이 CP949(EUC-KR)인 경우가 많은데, 알고 계시면 같이 알려주세요. 모르셔도 자동으로 확인해서 원래 인코딩을 유지하겠습니다.
