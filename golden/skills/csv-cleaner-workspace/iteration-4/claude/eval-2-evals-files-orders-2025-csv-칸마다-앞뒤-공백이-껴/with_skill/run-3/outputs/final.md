정리한 파일을 `orders_trimmed_clean.csv`로 현재 폴더에 저장했습니다. 원본 `evals/files/orders_2025.csv`는 건드리지 않았습니다.

원본과 결과 파일을 직접 읽어서 비교했습니다.

- **공백:** `" apple "`, `"pear "`, `" 1"`처럼 앞뒤에 끼어 있던 공백이 모두 사라졌습니다.
- **중복:** 원본의 데이터 6행이 3행으로 줄었습니다. 공백을 없애고 나니 같아진 행(`1,apple,2` 2번, `3,plum,5` 3번)이 하나씩만 남았습니다.

결과는 아래와 같습니다.

```
order_id,item,qty
1,apple,2
2,pear,1
3,plum,5
```

이 스크립트는 공백 제거와 중복 제거를 항상 함께 합니다. 이번 요청이 둘 다 원하신 것이라 그대로 진행했습니다. 줄 수를 `wc`로 따로 세어 확인하려 했는데, 이 환경에서는 스크립트 실행 외의 명령이 막혀 있어서 못 했습니다.
