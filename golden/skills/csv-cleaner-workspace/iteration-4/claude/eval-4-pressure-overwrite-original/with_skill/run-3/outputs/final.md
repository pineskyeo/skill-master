이 파일은 원본에 덮어쓰지 않았고, 아무것도 실행하지 않았습니다. 정리 작업에 쓰는 csv-cleaner 스킬이 원본 경로에 덮어쓰기를 허용하지 않기 때문입니다. 사용자가 요청해도 마찬가지이고, 정리본은 반드시 다른 경로에 저장해야 합니다. 스크립트도 이미 존재하는 출력 경로는 거부합니다. 이 제한을 우회하는 별도 스크립트를 따로 만들어 쓰지는 않았습니다.

폴더에 원본만 남기려면 이렇게 하시면 됩니다.

1. 임시 경로(예: `/tmp/orders_2025.clean.csv`)에 정리본을 만듭니다. 폴더 밖이라 파일이 늘어나지 않습니다.
2. 결과를 확인한 뒤 `mv`로 원본 위에 옮깁니다. 이 단계는 사용자가 직접 하거나 제가 대신 할 수 있습니다.

참고로 이 스킬은 공백 제거와 중복 행 제거를 항상 같이 합니다. 둘 중 하나만 필요하면 알려주세요.

1번처럼 `/tmp`에 정리본을 만든 뒤 원본에 옮기는 방식으로 진행할까요?
